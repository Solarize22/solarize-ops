Solarize CRM Import Instructions

This guide explains exactly how the CSV import works, what each column means, and how values are interpreted by the CRM.

Important: The importer creates and updates real CRM records.
Jobs go into the jobs table. Milestone dates update the job timeline. M1, M2, and adders create invoice records. Paid flags can create payment records.

Quick Rules

  1. Keep the header row exactly the same as the template.
  2. Use one job per row.
  3. For new imports, include job_id, customer, and either street or city.
  4. For update imports, job_id is required and blank cells do not overwrite existing values.
  5. Use dates like 03/21/2026 or 2026-03-21.
  6. Use Yes or No for payment flags and battery.

Status Options

Use these exact values in the status column when you want to explicitly set status from the CSV.

  • scheduled Job exists but install is not complete yet.
  • install_completed Install is done and the job is ready to move forward.
  • inspection_scheduled Inspection has been arranged but not passed yet.
  • inspection_passed Inspection is complete and approved.
  • pto_granted Utility has granted PTO.
  • m1_invoiced M1 invoice exists but is not fully paid.
  • m1_paid M1 invoice has been fully paid.
  • m2_invoiced M2 invoice exists but is not fully paid.
  • paid_in_full All invoices are paid.
  • on_hold Job has an issue and needs manual ops attention.
How status really works: If the CSV also includes stronger evidence like PTO date, paid M2, or invoice/payment data, the importer may derive the final CRM status from that evidence instead of a vague status word like complete.

Financial Flag Behavior

Column Expected format What the importer does
m1_invoice_number Invoice number like INV-1201 Creates or updates the M1 invoice record.
m1_amount Dollar amount like 9302 or 9302.00 Sets the M1 invoice total.
m1_status Yes or No Yes records a payment for the full M1 amount. No or blank does not create a payment.
m2_invoice_number Invoice number like INV-1202 Creates or updates the M2 invoice record.
m2_amount Dollar amount like 2326 or 2326.00 Sets the M2 invoice total.
m2_status Yes or No Yes records a payment for the full M2 amount. No or blank does not create a payment.
adders Dollar amount like 500 If greater than zero, creates an adder invoice.

Recommended Workflow Mapping

  • If install is done, include install_date.
  • If inspection passed, include inspection_date.
  • If PTO happened, include pto_date.
  • If M1 exists, include m1_invoice_number and m1_amount.
  • If M1 is paid, set m1_status to Yes.
  • If M2 exists, include m2_invoice_number and m2_amount.
  • If M2 is paid, set m2_status to Yes.
